# 方塊勇者：Boss Rush

以俄羅斯方塊為核心的單人瀏覽器遊戲。消除方塊列攻擊 Boss、在攻擊預告期間清除垃圾列，並一路挑戰五個關卡。

## 遊玩

- 線上遊玩：[GitHub Pages](https://5487556.github.io/block-hero-boss-rush/)
- 在電腦下載或複製專案後，直接用瀏覽器開啟 `index.html` 即可。遊戲不需要安裝套件或連接伺服器。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| ← / → | 移動；按住可連續移動 |
| ↓ | 按住軟降 |
| ↑ / X | 順時針旋轉 |
| Z / Ctrl | 逆時針旋轉 |
| Space | 硬降並立即鎖定 |
| C / Shift | 暫存或交換目前方塊，每塊限一次 |
| Esc / P / F1 | 暫停或繼續 |
| Enter / Space | 暫停時繼續；失敗或通關後重新開始 |

遊戲畫面也提供對應的觸控按鈕；左右移動和軟降按住時會持續生效。

## 遊戲規則

- 棋盤為 10 欄 × 20 列。方塊依 7-Bag 規則生成，預覽接下來三塊。
- 方塊觸地後有 500 ms 鎖定延遲；成功移動或旋轉可重置延遲，每塊最多 15 次。硬降會立即鎖定。
- 每關自然下落速度逐步提高，遊玩時間增加時也會繼續加速。
- 一次消除 N 行造成 `N × (N + 1) ÷ 2` 點基礎傷害；連續消行依 Combo 倍數增加傷害。
- Boss 會預告垃圾方塊攻擊。倒數期間每消除一行可抵銷一列垃圾方塊。
- 擊敗第五關 Boss 即通關；方塊堆滿棋盤頂端則挑戰失敗。
